## Lumtub 0.2.0

**YTPlus is now Lumtub.** Updating keeps your settings, library, downloads and sign-in: the data folder is renamed on first launch, and the installer replaces the old program and shortcuts.

### Highlights
- **Windows on ARM:** native arm64 packages, alongside x64 and x64-v3 (AVX2).
- **Portable mode:** the portable ZIP keeps its data in a `userdata` folder next to `lumtub.exe`.
- **Live chat** during broadcasts and replays.
- **Smoother playback:** a stream YouTube cuts off mid-way now continues instead of jumping to the end, and a video that stops is reopened where you were.
- **Downloads:** FFmpeg now comes from zhongfly/mpv-winbuild (LGPL, built for your CPU), with BtbN/FFmpeg-Builds as the fallback.

### Also new
- Faster lists: the next page loads well before you reach the end, and the home feed appears as soon as a few sources answer.
- Channel blocks from more places, and times for upcoming streams.
- Better format choice: quality first, then the decoder your PC handles best; software AVC when hardware decoding is off.
- A notice when an optional Windows video extension is missing.
- Native crashes are written to the log.
- Videos no longer fail to play when Lumtub is installed in a folder it cannot write to.

### Downloads
| Package | For |
|---|---|
| `x64-v3` | CPUs with AVX2, most from 2015 on |
| `x64` | Older x64 CPUs |
| `arm64` | Windows on ARM |

## Lumtub 0.2.0（中文）

**YTPlus 已更名为 Lumtub。** 更新后设置、收藏、下载和登录都会保留：首次启动时会自动改名数据文件夹，安装程序会替换旧程序和快捷方式。

- 新增 Windows ARM 原生版本，与 x64、x64-v3 一起提供。
- 便携版的数据保存在 `lumtub.exe` 旁的 `userdata` 文件夹。
- 直播和回放支持实时聊天。
- 播放更稳：视频流中途断开会接着播放，不再跳到结尾；中断后从原来的位置重新打开。
- 下载用的 FFmpeg 改为 zhongfly/mpv-winbuild 的 LGPL 版，按 CPU 选择，BtbN 版作为备用。
- 列表加载更快，首页更快出现；更多地方可以屏蔽频道；修复安装在只读目录时视频无法播放的问题。
