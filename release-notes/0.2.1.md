## Lumtub 0.2.1

### Fixed
- **Explore showed "No videos in this category"** in every mode except For you: a filter meant only for For you treated every video as a Short. All modes list videos again.
- An explore list that comes back empty on a fresh install is read again a few seconds later.
- On the watch page, Follow and the channel menu sit at the right edge again.

### Changed
- **Explore › All** is now plain popular videos from zones picked at random on each visit. It no longer mixes in your interests and skips videos you have watched or that your home feed already shows. Personal picks live on the home page; each zone keeps its For you order.
- The separate Recommended zone in Explore is gone; it duplicated All.
- Recommendations and the playback format choice now run in Lumtub's native core (`lumtub_core.dll`), built with the newest Rust and optimized for each package's CPU.
- Log messages are in English.

### Downloads
| Package | For |
|---|---|
| `x64-v3` | CPUs with AVX2, most from 2015 on |
| `x64` | Older x64 CPUs |
| `arm64` | Windows on ARM |

## Lumtub 0.2.1（中文）

- 修复探索里除“为你推荐”外都显示“这个分类暂时没有视频”的问题。
- 新安装时探索列表如果一开始是空的，几秒后会自动再读一次。
- 播放页的关注按钮和频道菜单恢复靠右对齐。
- 探索 › 全部改成每次随机挑几个分区的热门视频，不再夹带你的兴趣，也不再出现看过的和首页已推荐的视频；个性化推荐只在首页，各分区的“为你推荐”保留。
- 去掉探索里和“全部”重复的“推荐”分区。
- 推荐算法和画质选择改由原生核心（`lumtub_core.dll`）计算，用最新 Rust 编译并按 CPU 优化。
- 日志改为英文。
