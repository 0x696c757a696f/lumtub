## New look

- One design system across the app: consistent spacing, corner radii, text sizes and motion, neutral dark greys, and visible focus rings on buttons.
- New icon set (Phosphor, MIT licence), bundled as a font.

## Live chat

- Write in the live chat when signed in with the browser (cookie) sign-in. When this account cannot write there, the box says why.
- Translate a single chat message with the button that shows on hover, or a long press on touch screens.
- The chat no longer stalls on busy streams.

## Immersive translation

- New Immersive translation: foreign-language comments, posts, post comments and live chat show their translation underneath without asking. Turn it on from the chip above comments, posts and the chat, or in Settings › Translation & AI.
- It translates into the interface language by default; another language can be chosen. Text already in the interface or system language is left alone.
- Translation settings are simpler: the immersive switch and its language are one option, and Bilingual and Translation above the original became one Translation layout choice.

## Playback

- No more green line along the bottom of the video when fast scaling is used (low-resource mode or a busy GPU).
- The decoder padding crop is set on every video and again when the picture size changes.
- mpv no longer picks a stray subtitle on its own, and keeps the chosen format sort when it resolves the stream itself.
- Live streams whose format falls back to yt-dlp's default resolve again.

## Fixes

- The keyboard shortcut list scrolls instead of running off the window.
- yt-dlp reads and writes in UTF-8, so paths with non-ASCII characters work.
- The portable update script and its log are written in UTF-8.
- Subtitle downloads wait for the start-up cleanup instead of racing it.
- Subscriptions as the start page refreshes its feed; per-channel speed and volume are matched by video id.
