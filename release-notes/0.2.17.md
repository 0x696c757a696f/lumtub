## Subtitles

- The first subtitle no longer switches itself off. When the second subtitle is in the first one's language, the first one shows the language the video is spoken in, so you get the original with its translation. Only when the video is spoken in that language too does a single subtitle show, as the first subtitle.
- YouTube's captions in the language spoken ("xx-orig") are preferred, and they are no longer listed twice in the subtitle menu.

## Subtitle list

- A translation shown on its own is listed with the original lines beside it, whether it is the first or the second subtitle.
- A line YouTube's translation left empty joins the next line, which holds its words, so the original and the translation line up.
