## Bullet chat

- Live chat and chat replays can fly across the picture as bullet chat. Turn it on with the new button in the player controls, shown when a video has chat; it is off by default.
- Bullet chat settings: opacity, font size, how long a message takes to cross, the area it uses (top quarter, top half or full picture) and whether Super Chats and memberships show (in gold).
- On a live stream each message flies at the time it was sent, keeping the gaps between messages, and pauses with the video. In a chat replay messages fly at their moment in the video and follow seeking.
- Messages never overlap: when every lane is busy, a message is skipped.
- The text has a thin outline like Bilibili's and is laid out in the Rust core and drawn by mpv, so it costs the interface nothing.

## Theater mode

- The chat stays beside the video in a column on the right, which can be collapsed, when the window is at least 900 px wide.
