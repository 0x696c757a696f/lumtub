## macOS

- Lumtub for macOS is now part of the releases: `macos-arm64` for Apple silicon and `macos-x64` for Intel Macs. It is not notarized by Apple yet, so the first start needs one extra step, described in the README. After that it updates itself like the other versions.

## Window

- Minimize to tray: with the new switch in the playback settings, minimizing hides the window to the tray icon and off the taskbar; clicking the icon brings it back. On Windows it works with the minimize button, the taskbar, Win+M and Win+Down; on macOS with the yellow button and ⌘M. On Linux it works on X11, with Lumtub's own minimize button on GNOME and other Wayland desktops, and with every way of minimizing on KDE Plasma Wayland. Tiling compositors such as Hyprland, Sway and Niri have no minimizing at all.

## Settings

- The separate list of hardware-decoded codecs is gone. Which codecs play is set only by the codec choices; hardware decoding mode stays.
- Settings that another setting overrides now say so and are greyed out, instead of silently doing nothing: thumbnail quality and reduce animations under low resource mode, the app theme under a colour scheme, audio only when minimized while pause when minimized is on, and resume from last position while saving playback position is off.
- Frame interpolation now really works when video sync follows the audio: it switches to display-resample for it, as interpolation needs.

## Subtitles and translation

- The first subtitle, the second subtitle, the Translate button and immersive translation follow the interface language by default, and every one of the 72 interface languages can be picked for them. Before, only 16 could, and the rest fell back to Windows' language or English; Hong Kong Chinese now gets traditional Chinese.
- Subtitles are translated from the right track. A second subtitle translates the first one on screen (or what that one was translated from), so the two say the same thing line for line. A subtitle shown alone translates the creator's own subtitle in the language the video is spoken in, before YouTube's automatic one. Before, Lumtub could translate whichever track came first in the list, so a second subtitle might match the first in neither words nor timing.

## Explore

- Religion & faith no longer replaces the list of categories: the categories stay down the side with Religion & faith chosen, and the traditions (Christianity, Islam, Buddhism and the others) are a row of tabs above the videos. The "All categories" back button is gone; picking another category leaves it.

## Languages

- Every new string, including the live stream and tray ones and the names of all subtitle languages, is translated into all 72 interface languages.
