## Video cards

- Views and the upload date stay visible on every card; a long channel name is shortened instead.

## Installing

- Windows: Lumtub needs the Microsoft Visual C++ Redistributable. If Windows says `MSVCP140.dll` or `VCRUNTIME140_1.dll` is missing, install it ([x64](https://aka.ms/vs/17/release/vc_redist.x64.exe), [ARM64](https://aka.ms/vs/17/release/vc_redist.arm64.exe)) and start Lumtub again.
- Linux: if the AppImage says FUSE is missing, install your distribution's `fuse3` package, or start it with `--appimage-extract-and-run`.
- macOS and Android need nothing extra; see the README for the first-open steps.
