## Changes

- Translated subtitles no longer fail with "Too many translation requests". Google's free translation refuses a burst of requests from one address for a while; Lumtub now spaces its requests, waits when Google says it is busy (longer each time), asks again, and if Google still refuses, shows YouTube's own translation instead of none (all platforms).
- With Google Translate chosen (the default), comments, descriptions, chapter titles and live chat are translated with Microsoft's free translator first, so subtitles keep Google's allowance for whole-sentence translation. Any other chosen service still translates everything.
