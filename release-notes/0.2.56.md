## Changes

- Subtitles on portrait videos: subtitles now use the whole player instead of the narrow picture, so a bilingual line no longer wraps into many short lines. On phones held upright, subtitles stay on screen at a sensible size.
- Same clean outline for every language pair: a Polish, Czech, Ukrainian, Arabic or Thai video with a Chinese translation (or the other way round) now picks a font for each line, so its subtitles look like any other video's. Where Flutter still draws subtitles, it uses a solid outline like libmpv's.
- Accented Latin letters such as ś, ż, ć, ł and ę no longer show as boxes or with the accent out of place, in titles and in subtitles.
- Downloaded videos keep their online subtitles: when online, a downloaded video gets YouTube's subtitle list, translations included, and picks the first and second subtitle the same way as when it streams. Offline, a bilingual download shows its two languages styled as online, from files saved beside the video.
- MP4 downloads keep the styled ASS subtitle beside the video, so VLC, PotPlayer and mpv show it in the style Lumtub shows. The embedded MP4 subtitle also keeps the background box colour and the bottom margin.
- With "Cut from downloads" removing SponsorBlock stretches, the subtitle files beside the video now follow the cuts too.
- New choice under Turn on subtitles automatically: **On for languages I don't understand**. Videos spoken in a language from **Languages I understand** keep subtitles off.
- Subscriptions: Page Up and Page Down turn the All subscriptions list while its search field has focus, and a folder button beside Following puts the channel in subscription groups.
- The README and these notes link each package for direct download.
