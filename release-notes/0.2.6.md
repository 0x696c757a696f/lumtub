## Lumtub 0.2.6

### Updates
- **Updates install again.** An update was downloaded and verified, Lumtub closed, and nothing else happened: the hidden PowerShell script that was to run the installer did not start. Lumtub now starts the installer itself. It asks for administrator rights only when its folder needs them; declining leaves Lumtub running, with the reason in Settings › About. The installer waits for Lumtub to close, then starts it again as you, and notes how it went in the update logs Lumtub reads at its next start.
- **Install 0.2.6 by hand once.** The version that is running does the updating, so 0.2.5 still uses the old script; from 0.2.6 on, updates use the new way.
