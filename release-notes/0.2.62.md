## Changes

- **Two-language automatic captions say the same thing.** Each line of automatic captions is now translated on its own, so the original and the translation beside it always match and come and go together. Lines are at most one row on a phone. Before, the translation of a whole sentence was cut by length, and with a different word order the wrong half could end up beside a line. YouTube's own translation goes into the same lines too.
- **Subtitles in every script.** Lines that mix scripts use the right font for each part, 33 more scripts are supported, and Linux downloads Noto fonts for a script when it is first needed. The Chinese font is bundled again.
- **Picture in picture on iPhone and iPad shows subtitles**, from libass or from Lumtub's own subtitle drawing.
- **Updates are checked against yt-dlp's own signature.** A yt-dlp update is installed only when its checksums carry the signature of yt-dlp's release key.
- **Backup servers that really play.** Piped and Invidious servers are used only after they have fetched a short video, not when they merely answer. The built-in lists now hold the servers that still work.
- **A whole-app review fixed about 200 problems.** The main ones:
  - Library saves no longer fail when a group, list or key name contains `"` or `\`.
  - Overlapping saves can no longer damage your word lists.
  - Broken video files no longer crash or hang cut, join or record.
  - A keyring that fails for a moment no longer causes secrets to be written unsealed.
  - Events from the previous video no longer skip, remove or reopen the next one.
  - Leaving playback stops the live chat, bullet chat and reconnects.
  - A signed-in download leaves no cookies on disk.
  - Long lists, feeds and sessions use less CPU and memory.
  - Screen readers can use the seek bar and the skinned window buttons.
- **Faster reading of subtitles, storyboards, relay answers and search suggestions.** These are now read by Lumtub's Rust core, with size limits on everything that comes from the network.
- All 81 interface languages are complete.
- Linux: the stats overlay no longer crashes the player. AppImages carry update information for AppImageUpdate and Gear Lever.
- Tooltips follow the light or dark theme. In dark mode, cards in Soft Club, Silk Wave and Brutal stay readable while pointed at.
