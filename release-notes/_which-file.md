
## Which file to download

| Your device | File |
|---|---|
| Windows PC from 2015 on (AVX2) — **pick this if unsure** | `windows-x64-v3-setup.exe` (installer) or `windows-x64-v3.zip` (portable) |
| Older Windows PC | `windows-x64-setup.exe` or `windows-x64.zip` |
| Windows on ARM | `windows-arm64-setup.exe` or `windows-arm64.zip` |
| Mac with Apple silicon (M1 and later) | `macos-arm64.dmg` |
| Intel Mac | `macos-x64.dmg` |
| Linux PC from 2015 on (AVX2) — **pick this if unsure** | `linux-x64-v3.AppImage` |
| Older 64-bit Linux PC | `linux-x64.AppImage`, or `linux-x64.flatpak` |
| ARM64 Linux, such as a Raspberry Pi 5 | `linux-arm64.AppImage`, or `linux-arm64.flatpak` |
| Most Android phones, tablets and TVs — **pick this if unsure** | `android-arm64-v8a.apk` |
| Older 32-bit Android devices and many TV boxes | `android-armeabi-v7a.apk` |
| Android emulators and x86 Chromebooks | `android-x86_64.apk` |
| iPhone and iPad (preview, sideloaded) | `ios.ipa` |
<!-- package managers -->

Each file has a `.sig` next to it, which Lumtub checks before it installs an update. The AppImage, the Windows packages, the DMG and the APK update themselves from inside Lumtub; a Flatpak bundle does not, so install the next one by hand. More help: [Get it](https://github.com/0x696c757a696f/lumtub#get-it).
