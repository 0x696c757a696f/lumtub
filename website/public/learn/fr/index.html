Installation

Windows Mac (Apple silicon) Mac (Intel) Linux AppImage

PC ancien ou Windows sur ARM ? Voir tous les téléchargements.

Windows

  1. Lancez l'installeur. Pas besoin de droits d'administrateur.
  2. Si Windows affiche Windows a protégé votre ordinateur : cliquez sur Informations complémentaires, puis Exécuter quand même. Ce message apparaît parce que Lumtub n'est pas encore signé avec un certificat payant.

Mac

  1. Ouvrez le DMG et glissez Lumtub dans Applications.
  2. La première fois, macOS le bloque car il n'est pas encore notarié par Apple. Cliquez sur OK, puis allez dans Réglages Système › Confidentialité et sécurité et cliquez sur Ouvrir quand même à côté de Lumtub.
  3. Ou lancez une fois dans le Terminal : xattr -dr com.apple.quarantine /Applications/Lumtub.app

Linux

  1. Rendez le fichier exécutable : chmod +x Lumtub_*.AppImage, puis lancez-le.
  2. S'il indique que FUSE manque, installez le paquet fuse3 de votre distribution.

Ensuite

Ouvrez une vidéo avec des sous-titres dans la langue que vous apprenez et cliquez sur un mot. La première fois, Lumtub propose de télécharger le dictionnaire de cette langue.
