Install

Windows Mac (Apple silicon) Mac (Intel) Linux AppImage

Older PC or Windows on ARM? See all downloads.

Windows

  1. Run the installer. No administrator rights needed.
  2. If Windows shows Windows protected your PC: click More info, then Run anyway. This appears because Lumtub isn't signed with a paid certificate yet.

Mac

  1. Open the DMG and drag Lumtub into Applications.
  2. The first time, macOS stops it because it isn't notarized by Apple yet. Click Done, then go to System Settings › Privacy & Security and click Open Anyway next to Lumtub.
  3. Or run this once in Terminal: xattr -dr com.apple.quarantine /Applications/Lumtub.app

Linux

  1. Make the file executable: chmod +x Lumtub_*.AppImage, then run it.
  2. If it says FUSE is missing, install your distribution's fuse3 package.

Then

Open a video with subtitles in the language you're learning and tap a word. The first time, Lumtub asks to download that language's dictionary.
