安装

Windows Mac（M 系列芯片） Mac（Intel） Linux AppImage

电脑比较老，或者是 ARM 版 Windows？看全部下载。

Windows

  1. 运行安装程序，不需要管理员权限。
  2. 如果提示「Windows 已保护你的电脑」：点「更多信息」，再点「仍要运行」。出现这个提示是因为 Lumtub 还没有买付费的代码签名证书。

Mac

  1. 打开 DMG，把 Lumtub 拖进「应用程序」。
  2. 第一次打开时，macOS 会拦下来，因为还没经过苹果公证。点「完成」，然后去「系统设置 › 隐私与安全性」，在 Lumtub 旁边点「仍要打开」。
  3. 或者在终端里运行一次：xattr -dr com.apple.quarantine /Applications/Lumtub.app

Linux

  1. 给文件加上执行权限：chmod +x Lumtub_*.AppImage，然后运行。
  2. 如果提示缺少 FUSE，安装发行版的 fuse3 包。

然后

打开一个有你在学的语言字幕的视频，点一个词。第一次会问你要不要下载这种语言的词典。
